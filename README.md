# Attendance Tracking System

The Attendance Tracker System is a Java-based desktop application that helps manage employee attendance efficiently. It uses JDBC (Java Database Connectivity) to connect with a MySQL database, enabling users to add, update, view, and track attendance records securely.
This project demonstrates how core Java and database integration can be used to build real-world CRUD (Create, Read, Update, Delete) applications.


🚀 How to Run:
Install MySQL and create a database named attendance_db.
Import the provided SQL file to create necessary tables.
Add the MySQL JDBC connector .jar file to your project’s classpath.
Run the MainTracker.java file to launch the system.
